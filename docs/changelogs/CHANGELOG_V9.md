# Registro de cambios — SKY v9.0

## Incorporado
- 33 roles de asistencia con selección automática y combinación por temas.
- API `api/sky`: planeación, tareas, aprobaciones y resultados exportables.
- Persistencia personal SQLite y descarga autenticada de artefactos.
- Diseño HTML/CSS local con seis tipos de plantillas y cuatro paletas.
- Panel Neural Core sobre eventos de API reales.
- Integración visual desde el menú de Office Studio, comunidad y metaverso.
- Respaldo extendido a Workbench, telemetría, memoria evolutiva y archivos.
- Pruebas de contrato para permisos, descargas, documentos, mundos y memoria.

## Compatibilidad

Sin eliminación de rutas v8, sin modificaciones a las bases antiguas y sin cambios
en el repositorio de BAQUEANO. Mantiene API `/api/worlds`, `/api/community`,
`/api/office`, `/v1/chat/completions` y panel Streamlit anterior.

## Pendiente para lanzamiento mundial

- Revisiones UX accesibilidad y usabilidad reales en Android, iOS y navegadores.
- Pruebas de carga, estrés y seguridad; protección contra abuso y moderación.
- Identidad, permisos detallados, cifrado en reposo, HTTPS, autenticación federada.
- Arquitectura escalable y disponibilidad 24/7 monitorizada.
- Integraciones multimedia GPU/modelos 3D avanzados y motores VR.
- Verificación de IP y marca SKY IA con autoridades correspondientes.
