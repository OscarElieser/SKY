# SKY v9.7 — Creative Studio y Reliability

**Agregado**: biblioteca privada multimedia, motor de edición Pillow por capas, motor de montaje MP4 FFmpeg, editor web interno, prompts locales de edición auditables, generación opcional Gemini, biblioteca compartida entre proyectos y portabilidad `.skyzip`.

**Integración**: página accesible solo desde menú `Espacios` (no botones añadidos a la portada), Project Hub enlaza `creative`, exporta recetas y medios por cuota, Backup extendido agrega datos y medios creativos, Preflight vigila la base multimedia y distingue disponibilidad de FFmpeg.

**Fiabilidad**: recetas editables versionadas con bloqueo optimista, instantánea de las tareas de render al ponerlas en cola, historial de trabajos, reintentos manuales, estados `needs_review`, SHA-256 de medios, validación por contenido y límites por tamaño/duración.

**Compatibilidad**: se conservan metaverso, Neural Core, Multi-IA, Office Studio, Workflows, BAQUEANO privado y proyectos v9.6. No se han cambiado datos ni código de BAQUEANO en producción.

**No incluido**: paridad completa Photoshop/Premiere/CapCut, generación de películas enteras desde prompts, editor 3D animado profesional, pruebas con GPU o cargas masivas públicas.
