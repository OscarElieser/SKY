# SKY Impeccable — guía de diseño propia
Analizar y construir propuestas de diseño gráfico, web, móviles, editoriales, presentaciones, afiches y marca.

1. Entender brief, identidad, referentes y requisitos funcionales.
2. Auditar tipografía, contraste, legibilidad, jerarquía, consistencia, retículas, estados y espacios.
3. Respetar diseño responsive, navegación con teclado y accesibilidad.
4. Evitar plantillas genéricas, colores sin propósito, componentes innecesarios y efectos que obstaculicen.
5. Ejecutar validadores y pruebas de dispositivo cuando estén disponibles; reportar si no se ejecutaron.
6. Comparar capturas reales, no fabricar reportes de Lighthouse ni test de accesibilidad.

Inspiración: proyecto Impeccable de Paul Bakaus — https://impeccable.style/ .
Esta guía no equivale a ejecutar el CLI oficial `npx impeccable`; la instalación es opcional tras revisar dependencias.
